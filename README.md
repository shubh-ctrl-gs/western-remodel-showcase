# Western Remodel Showcase

Create a high-impact desktop layout (1440px wide) for a commercial contractor ("Western Multi-Family Remodel").

Design Foundations:

- Palette: Dark Navy (#0A192F), Slate Gray (#334155), Construction Gold/Amber (#F59E0B), Clean White (#FFFFFF).

- Fonts: Inter or Montserrat (Headers: 700/800 bold; Body: 400/500 regular).

Component Structure:

1. Utility Bar (36px height, Dark Slate background):

   - Right-aligned contact: "(714) 920-9947 | Office: (714) 299-9722"

2. Sticky Header (80px height, White background, bottom subtle shadow):

   - Left: Container frame for PNG Logo (`wmfr-logo.png`).

   - Right: Horizontal nav bar with tabs:

     - Home

     - About

     - Services [Include pill badge "NEW: Custom Remodel"]

     - Our Process

     - Portfolio / Case Studies

     - Contact

   - Far Right: "Request a Quote" CTA Button (Amber background, white bold text).

3. Hero Intro Section (White background):

   - H1 Tag (48px, Navy): "WMFR has set the standard for our ability to Fast-Track comprehensive CAPEX interior remodel on Large, up to 1200+ unit, multi-family projects, WHILE OCCUPIED."

   - Highlight Box (Slate background, Gold border): "Completing 3 units PER Trade Per Day, we reduced the original projected length of the project by 1 year and 4 months."

   - Body Block: Copy regarding AvalonBay Communities / AVA Toluca Hills partnership.

4. Aerial Drone Site Map Container (Full-width 600px height):

   - Dark background placeholder for drone orthomosaic image.

   - Floating glassmorphism badge (Top Center): "TOTAL UNITS COMPLETED: 1,151".

   - Bottom Right Overlay CTA Button: "Explore Full Toluca Hills Case Study →".
